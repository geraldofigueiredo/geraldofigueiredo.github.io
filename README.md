# My Personal Blog

This is my personal blog, a project that I've always wanted to start but never did. I've tried a few times, but I always got stuck on the infrastructure, how to build and host it, and I ended up giving up without creating any content.

Now, with the experience I have, I decided to use my 2025 year-end vacation to make this initiative real. My intention is not to be a tutorial blog, but to share my vision and experience. I may have a tutorial here and there, but that will not be the focus.
